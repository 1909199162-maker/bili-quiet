# 静一静 · 文件说明

这个文件夹就是一个浏览器插件。**不要删里面的文件，也不要把它移到别的地方**（移动了要去 `edge://extensions` 重新加载一次）。

| 文件 | 干什么 | 你以后会改它吗 |
|---|---|---|
| `manifest.json` | 说明书：插件名字、版本、在哪些网站生效、点图标弹哪个页面 | 偶尔（改名字/版本/权限） |
| `content.js` | 真正干活的代码：进 B站 页面，把推荐流藏起来 | **经常**（想多藏一块东西就改这里） |
| `popup.html` | 点插件图标弹出的那个 280px 小窗 | 偶尔（改文字/样式） |
| `README.md` | 就是你现在看的这个说明 | 随便 |

## 装进 Edge

1. 地址栏输入 `edge://extensions`
2. 左下角打开「开发人员模式」
3. 点「加载解压缩的扩展」
4. 选中**这个文件夹**（`D:\DSH\projects\bili-quiet`，不是里面的某个文件）
5. 点右上角拼图图标，把「静一静」固定到工具栏

## 改了代码之后

```
改文件 → 回 edge://extensions 点「重新加载」→ 回 B站 按 F5
```

**只按 F5 不重新加载插件，浏览器用的还是旧代码。**

## 想让它多藏一块东西

打开 `content.js`，第一行的列表里加个选择器：

```js
const HIDE = [".feed2", ".recommended-container_overseas"];
```

怎么找选择器：B站 页面按 `F12` → `Ctrl+Shift+C` → 点你想藏的那块 → 看右边高亮的 `class="..."`，然后写成 `.类名`。
